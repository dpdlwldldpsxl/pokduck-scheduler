# 폭덕이 AI 코치 - 제품 기획서

## 왜 만드는가?

영어/드럼/사운드 학원 3개 + 필라테스 + 회사(9-6, 야근 있음)를 동시에 하면서:
- **일정이 머릿속에서 엉킴** → 까먹고 겹침
- **배운 게 휘발됨** → 수업 듣고 돌아서면 기억 안 남
- **번아웃** → 너무 많은 걸 하다 보니 지치고 산만
- **뭘 먼저 해야 할지 모름** → 시간은 있는데 비효율적

**해결책:** 폭덕이(AI 코치)가 일정 관리 + 멘탈 케어 + 학습 최적화를 통합 지원

---

## 핵심 기능 4가지

### 1. 스마트 일정 관리 (최우선)
> "오늘 뭐 해야 하지?" 를 안 물어보게

- **학원/회사/운동 통합 캘린더**
  - 영어(월/수 08:05), 드럼(토 15:00), 사운드(목 19:00)
  - 필라테스(월/수 20:00, 토 11:00)
  - 회사(평일 09:00~18:00, 야근 가능)
- **오늘 해야 할 일 자동 정리**
  - 고정 일정 + 할 일 → 타임라인으로 보여줌
  - "6시에 퇴근하면 → 8시 필라테스 전 1시간 영어 복습 추천"
- **야근 모드**
  - "오늘 야근이야" 버튼 → AI가 일정 자동 재배치
  - 학원 못 가는 날 대체 학습 추천
- **리마인더**
  - 수업 30분 전 알림
  - "내일 드럼 레슨인데 준비할 거 있어?"

### 2. AI 코칭 채팅 (실시간 상담)
> 힘들 때, 고민될 때 바로 폭덕이에게

- **실시간 대화**
  - "오늘 너무 힘들어" → 멘탈 케어 + 일정 조정 제안
  - "영어 공부 어떻게 해야 효율적이야?" → 뇌과학 기반 조언
  - "이번 주 너무 빡세" → 포기할 것 추천 + 우선순위 정리
- **유저 컨텍스트 반영**
  - 폭덕이가 내 일정, 기분 기록, 학습 이력을 알고 대화
  - "지난주 화요일에 집중력 낮았는데, 이번 주는 야근 없으니 그때 영어 집중해볼까?"
- **대화 유형**
  - 일정 상담 / 멘탈 케어 / 학습 조언 / 자유 대화

### 3. 학습 복습 시스템
> 배운 걸 까먹지 않게

- **수업 후 간단 기록**
  - 수업 끝나고 "오늘 뭐 배웠어?" → 핵심만 메모
  - 영어: 오늘 배운 표현 / 드럼: 오늘 연습한 패턴 / 사운드: 배운 기법
- **AI 복습 리마인더**
  - 에빙하우스 망각곡선 기반 복습 시점 알림
  - 1일 후 → 3일 후 → 7일 후 → 30일 후
  - "3일 전에 배운 영어 표현 기억나? 퀴즈 해볼까?"
- **주간 학습 리포트**
  - 이번 주 각 학원에서 배운 것 요약
  - 복습 달성률

### 4. 기분/컨디션 트래커
> 내 패턴을 알아야 관리할 수 있다

- **매일 30초 체크인**
  - 기분 (1~5) / 에너지 (1~5) / 집중력 (1~5)
  - 한 줄 메모 (선택)
- **AI 패턴 분석**
  - "화요일 오후에 집중력이 항상 낮네요 → 이때는 가벼운 복습만"
  - "필라테스 한 다음 날 에너지가 높아요 → 운동 후 학습 효과 UP"
- **번아웃 감지**
  - 3일 연속 기분/에너지 낮으면 → "쉬어가는 건 어때?"
  - AI가 일정 축소 제안

## 유저 플로우

```
[구글 로그인] → [닉네임 설정] → [학원/일정 초기 설정]
                                         ↓
                                  [메인 대시보드]
                                   ├── 오늘 탭: 타임라인 + 할 일 + 컨디션 체크
                                   ├── 일정 탭: 학원/회사/운동 관리
                                   ├── 코칭 탭: 폭덕이와 대화
                                   ├── 기분 탭: 컨디션 기록 + 분석
                                   └── 목표 탭: 학습 기록 + 복습 + 습관
```

## 개발 우선순위 (수정된 Phase)

### Phase 2: 스마트 일정 관리 ← 지금 여기부터
- 학원/회사/운동 등록 UI
- 요일별 일정 관리
- 오늘 타임라인 뷰
- 야근 모드 토글
- AI 일정 재배치 추천

### Phase 3: AI 코칭 채팅
- 폭덕이 채팅 UI
- 유저 컨텍스트 주입 (일정 + 기분 + 학습)
- 실시간 대화 (스트리밍)
- 대화 유형별 시스템 프롬프트

### Phase 4: 기분/컨디션 트래커
- 매일 30초 체크인 UI
- 주간 차트
- AI 패턴 분석
- 번아웃 감지 알림

### Phase 5: 학습 복습 시스템
- 수업 후 메모 기능
- 망각곡선 기반 복습 알림
- 주간 학습 리포트

### Phase 6: 통합 + 마무리
- 대시보드 리디자인
- 모든 데이터 AI 코칭에 반영
- 푸시 알림
- 설정 페이지

## 폭덕이 캐릭터 설정

| 상황 | 폭덕이 반응 |
|---|---|
| 일정 완수 | "오늘 진짜 잘했어! 폭덕이가 자랑스러워!" |
| 번아웃 감지 | "무리하지 마... 쉬는 것도 실력이야" |
| 야근할 때 | "오늘은 야근이구나. 학원은 내일 하자, 오늘은 푹 쉬어" |
| 복습 시간 | "3일 전에 배운 영어 표현 기억나? 같이 복습하자!" |
| 기분 안 좋을 때 | "힘든 날도 있지... 폭덕이가 옆에 있을게" |

## 기술 스택 (확정)

- **프론트엔드**: Vite + React 18 + react-router-dom
- **DB + Auth**: Supabase (PostgreSQL + Google OAuth)
- **AI**: Claude API (코칭: Sonnet, 분석: Opus)
- **차트**: recharts
- **배포**: Vercel
- **PWA**: 모바일 홈 화면 추가 지원

## 검증 방법

각 Phase 완료 후:
1. `npm run dev`로 로컬 실행
2. 구글 로그인 → 해당 기능 테스트
3. `npm run build`로 빌드 확인
4. 다른 계정으로 데이터 격리 확인
