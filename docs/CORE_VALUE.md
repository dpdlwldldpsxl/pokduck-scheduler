## 2. 핵심 가치 (한 줄)

> **"대화 못해도 내 삶을 분석해주는 AI 라이프 코치"**
> (일정만 넣으면 맹점을 짚어주는 AI)

**진입 모델:** 데이터 입력 → AI 분석 → 대화 (유저는 반응만)
**금지 모델:** 빈 채팅창 → "오늘 어때?" → 유저 막막 → 이탈

---

## 3. 4가지 차별점

1. **데이터가 먼저, AI가 분석** — 공감형 챗봇 아님. 패턴/맹점 탐지기
2. **멀티태스커 특화** — 학원 + 본업 + 운동 다 하는 사람 전용
3. **코치 + 친구** — 전문 조언 + 편한 말투
4. **시간이 가이드** — 아침/저녁에 따라 앱이 모드 전환. 유저는 결정 안 함

---

## 4. 타겟 페르소나

### 🟢 맞는 사람 — "에너지 고갈된 멀티태스커"
- 20대 후반~30대 초반
- 학원 2~3개 + 본업 + 운동/사이드
- 일기 써봤지만 3일 가고 포기
- ChatGPT/Claude 써본 경험
- 자기 성찰 필요성 느낌 but 에너지 부족
- 멘탈 관리 필요 but 상담은 부담

### 🔴 안 맞는 사람
- 종이 다이어리파 (쓰기 자체가 의미)
- 단순 할 일만 원하는 사람
- AI 불신
- 프라이버시 걱정 많음

**모든 기능 결정은 "🟢 페르소나가 원하는가?"로 판단.**

## 5. 6가지 원칙 (킵고잉)

### 원칙 1: "왜?" 매주 다시 쓰기
현재 Why: "에너지 없어도 자기 복기 되게."
흔들리면 위험 신호.

### 원칙 2: 기능 추가 전 3질문
1. 핵심 가치에 기여?
2. 빼도 돼?
3. 🟢 페르소나가 원해?
→ 하나라도 NO = 안 만듦

### 원칙 3: 삭제 > 추가
- 5탭 → 4탭 (기분 탭 삭제)
- 4탭 → 3탭 가능성 열어둠
- 기능 합치는 게 쪼개는 것보다 강함

### 원칙 4: 전문 앱 테스트 (욕심 덫 방지)
> "이거 [전문 앱]이 더 잘하지 않아?"

- 영어 복습 콘텐츠 → Anki/Duolingo 이김 ❌
- 가이드 명상 → Calm/Headspace 이김 ❌
- 할 일 정교 관리 → Todoist 이김 ❌
- 긴 일기 → Day One 이김 ❌

**전문 앱이 이기면 만들지 말고 "연결/허브"만.**
폭덕이 = 인터페이스. 전문성은 밖에서 빌려옴.

### 원칙 5: WISHLIST 시스템 (욕심 배출구)
만들고 싶은 아이디어는 `docs/WISHLIST.md`에 **적어만 둠**.
쓰면 욕심 풀림. 나중에 MVP 검증 후 꺼내서 재평가.

### 원칙 6: 결정을 유저에게 넘기지 않는다
다이어리 실패 1순위 = 결정 피로.
"아침? 저녁? 뭘 써? 언제?" 고민하는 순간 에너지 고갈 → 이탈.

**앱이 "지금 이거 해" 먼저 제안, 유저는 Yes/No만.**
- 언제 쓸지 = 시간이 자동 결정
- 뭘 쓸지 = 폭덕이가 구체 질문 던짐
- 어떤 앰비언트 = 기본값 자동 + 기분 매칭
- 첫 화면 = 시간대 맞춰 자동 전환

유저 결정권은 "끄기/바꾸기"에만.

## 7. 4탭 구조 (Phase D에서 실행)

```
📅 오늘(메인) │ 🗓️ 일정 │ 📒 기록 │ 🦆 코칭
     ↑                       ↑          ↑
  시간대별 UI           자산 누적    AI 분석 받기
```

- **오늘**: 데이터 입력 + 시간대별 모드 (설계/점검/복기)
- **일정**: 학원/회사/운동 스케줄 관리
- **기록**: 학습 메모 + 습관 + 목표 + 복습 알림
- **코칭**: AI 분석 카드 먼저, 대화는 반응 중심
- 설정: 우상단 ⚙️
