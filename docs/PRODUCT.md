# 폭덕이 AI 코치 — 서비스 명세

> 문서 종류: **외부 공유 + 내부 핑퐁용** 살아있는 명세서
> 마지막 업데이트: 2026-04-29
> 빌드 상태: MVP (Phase A·B·D 완료 / 스마트 추천 + 페르소나 도입)
> 배포: https://pokduck-scheduler.vercel.app

---

## 1️⃣ 한 줄 소개

> **"대화 못해도 내 삶을 분석해주는 AI 라이프 코치"**

일정만 입력해두면 AI 캐릭터(폭덕이)가 패턴을 읽고 **먼저 말 걸어줌**.
"오늘 어땠어?" 같은 빈 채팅창 X. 데이터 → AI 분석 → 대화.

---

## 2️⃣ 누가 쓰는가

### 🟢 타겟: "에너지 고갈된 멀티태스커"
- 20대 후반 ~ 30대 초반
- 학원 2~3개 + 본업 + 운동/사이드
- 일기 써봤지만 3일 가고 포기
- 자기 성찰 필요 but 에너지 부족
- 멘탈 관리 필요 but 임상 상담은 부담

### 🔴 타겟 아님
- 종이 다이어리파 (쓰기 자체가 의미)
- 단순 to-do만 원함
- AI 불신
- 임상 상담을 기대하는 사람

## 3️⃣ 해결하는 페인포인트

| 유저 고통 | 폭덕이의 답 |
|---|---|
| "일기 쓸 에너지 없어" | 1탭 기분/에너지 입력. 글쓰기 X |
| "내가 왜 힘든지 모르겠어" | AI가 7일 데이터 분석해 패턴 짚음 |
| "오늘 뭐부터 해야 할지 모르겠어" | 시간대 + 컨디션 기반 추천 1개 |
| "배운 거 자꾸 까먹어" | 자동 에빙하우스 복습 알림 |
| "상담은 부담" | 친구 톤(50) + 전문 코칭(50) |
| "쓸 거 결정하기도 귀찮아" | 시간이 모드 결정 (아침=설계, 저녁=복기) |

## 4️⃣ 차별화 (Why 폭덕이?)

### 비교 매트릭스

| 기능 | Daylio | Finch | Notion | Replika | Calm | **폭덕이** |
|---|:-:|:-:|:-:|:-:|:-:|:-:|
| 1탭 기분 트래킹 | ✅ | ⚪ | ❌ | ❌ | ❌ | ✅ |
| AI 분석/예측 | ❌ | ❌ | ❌ | ⚪ | ❌ | ✅ |
| 스케줄 연동 | ❌ | ❌ | ⚪ | ❌ | ❌ | ✅ |
| 학습 복습 시스템 | ❌ | ❌ | ❌ | ❌ | ❌ | ✅ |
| 캐릭터 감성 | ⚪ | ✅ | ❌ | ✅ | ❌ | ✅ |
| 데이터→대화 자동 | ❌ | ❌ | ❌ | ❌ | ❌ | ✅ |
| 명상/사운드 | ❌ | ❌ | ❌ | ❌ | ✅ | ⚪ |
| 시각화 통계 | ✅ | ⚪ | ⚪ | ❌ | ❌ | ⚪ |

**폭덕이의 자리:** 빈 시장 — **"데이터 + AI 대화 + 라이프 코칭"** 교집합.

기존 앱은 한 영역만 깊음:
- Daylio = 기록만 / Finch = 캐릭터만 / Replika = 대화만 / Calm = 명상만

폭덕이 = 기록 + 캐릭터 + 대화 + 분석 통합 (얕지만 연결됨).

## 5️⃣ 핵심 기능 (현재 구현됨)

### 📅 오늘 탭
- **기분 1탭 입력**: 😫번아웃 / 😤짜증 / 🤔복잡 / 😌평온 / 😊좋음 (하루 1개, 변경 가능)
- **에너지 1탭 입력**: 😴피곤 / 😶보통 / 💪좋음 / 😵‍💫멍함 / 🤕아픔
- **오늘 일정 타임라인** (일정 탭에서 등록한 거 자동 표시)
- **해야 할 일** — 미완료 이월 / 어제 이전 완료된 건 자동 숨김
- **🦆 폭덕이 스마트 제안** — 우선순위 엔진 기반 추천 1개:
  - 신체 경고(아픔) → "일정 최소만 하고 일찍 자자"
  - 복습 타이밍 → "어제 영어 'X' 오늘 복습 타이밍 → [복습하러 가기]"
  - 오전 9~11시 → "지금이 뇌 논리 최고점, 어려운 거 먼저"
  - 점심 직후 → "집중력 저점 — 단순 작업부터"
  - 저녁 → "오늘 어땠어? → [폭덕이랑 대화]"

### 🗓️ 일정 탭
- 학원/활동 등록 (프리셋 7개: 영어/드럼/사운드/필라테스/회사/약속/개인 + 커스텀)
- 주간 캘린더 (이번 주 표시)
- 일정 추가:
  - 요일 멀티 선택 + 프리셋 (평일/주말/매일/월수금/화목)
  - 시간 프리셋 (9-18 출근/오전/오후/저녁/학원 1h 등)
  - 활동 선택 시 일정 이름 자동 채움

### 📒 기록 탭
3개 서브탭:
- **📝 메모**: 학습 메모 한 줄 입력 → 자동 에빙하우스 복습 (1→3→7→14→30일)
- **🔥 습관**: 매일 체크박스 + 스트릭 카운트
- **🎯 목표**: 마감 있는 목표 추가 + 완료 체크
- 각 서브탭 빈 상태 → 폭덕이 가이드 (예시 + 팁)

### 🦆 코칭 탭
- **4가지 유형**:
  - 💬 자유 대화 — 일상 톤
  - 📅 일정 상담 — 시간 관리 전문가
  - 💭 마음 털기 — 공감 우선 (임상 X)
  - 📚 학습 조언 — 능동 회상 강제
- **데이터 기반 오프닝** — 진입 시 폭덕이가 분석으로 먼저 말 검 (빈 채팅창 X)
- **Cold start 분기** — 데이터 zero/light/rich 따라 인사 톤 자동
- **시간대별 톤** — 아침(설계) / 낮(점검) / 저녁(복기) / 심야(쉼)
- **🎵 앰비언트 사운드** (코칭 진입 시 자동 + 셀렉터):
  - 자연: 🌧️비 🌊파도 🌳숲 🔥불멍
  - 음악: 🎧로파이 🎹피아노 💿힙합 🎛️EDM
  - 🔇 끄기

### 🎭 폭덕이 페르소나 (모든 코칭에 주입)

```
톤: 친구 50% + 전문가 50%
예측: 가설(중) → 검증 후 강하게 (패턴+논리+인과+시간 4요소)
결정: 추천 명확 + 이유 한 줄 + 선택권 열어둠
신뢰: 기억/관찰/전문성/한계 인정 표현 매 대화 1~2개
금지: 임상 진단·약물·호르몬 추정·트라우마 탐색·단정 미래·비교·가스라이팅
```

유형별 비율 오버라이드:
- 자유 대화: 친구 60 (가벼움)
- 일정 상담: 전문가 60 (시간 단위 명확)
- 마음 털기: 친구 70 (공감 우선)
- 학습 조언: 전문가 60 (회상 강제)

### AI 프롬프트 5층 구조

```
1. 캐릭터 + 공통 규칙        (코드 상수: BASE_PROMPT)
2. 베이스 페르소나           (docs/PERSONA.md)
3. 유형별 가이드             (docs/coaching-prompts/{type}.md)
4. 시간대 가이드             (코드 상수, KST 시간 기반)
5. 유저 실시간 데이터        (DB 쿼리 → 7일 트렌드 + 일정 + 메모 + 습관)
```

## 7️⃣ 디자인 원칙 (요약)

상세: [`docs/CORE_VALUE.md`](CORE_VALUE.md)

1. **"왜?" 매주 다시 쓰기** — 흔들리지 않게
2. **3질문** (핵심가치 기여? / 빼도 돼? / 페르소나 원해?)
3. **삭제 > 추가** — 5탭 → 4탭, 기분 탭 흡수 등
4. **전문 앱 테스트** — Anki/Calm/Day One 이기는 영역은 안 만듦
5. **WISHLIST 시스템** — "지금 만들고 싶은" 충동을 적어만 둠
6. **결정 피로 제거** — 유저가 "언제 뭐 할지" 고민 안 하게

## 8️⃣ 로드맵

### ✅ 완료
- **Phase A**: 기획 정렬 (페르소나/원칙/안 할 것)
- **Phase B**: 코칭 고도화 (기분/에너지 + 5-layer 프롬프트 + 데이터 오프닝 + Cold start + 시간대 + 앰비언트)
- **Phase D**: 구조 정리 (5탭 → 4탭, 멘탈 케어 → 마음 털기)
- **추가**: 스마트 추천 엔진, 페르소나 레이어, 일정 UX 개선

### 🔜 다음 후보
- **Phase E**: 온보딩 + 캐릭터 강화
  - 첫 로그인 튜토리얼
  - 폭덕이 다이얼로그 풍부화
- **Phase F**: 베타 테스트
  - 친구 3~5명 초대
  - 1주 피드백 → 페르소나 검증
- **Phase G**: 스마트 확장
  - 빈 시간 자동 학습 추천 (코르티솔 매칭 강화)
  - 야근 패턴 감지
  - 월간/연간 AI 요약 카드

### 📌 보류 (WISHLIST.md)
- 날씨 연동 자동 비소리 (Phase F 이후)
- 활동 태그 시스템 (Daylio식 — 검토 중)
- Sound Level 3 (3분 사운드 쉼)

## 🔟 폭덕이를 한 마디로 (엘리베이터 피치)

> "Notion은 입력만 받고, Calm은 명상만 시키고, Daylio는 기록만 보여주고, ChatGPT는 내 데이터 모르죠.
> 폭덕이는 일정·기분·습관 다 모아서 **AI가 먼저 패턴 짚고 친구처럼 말 걸어주는** 라이프 코치예요.
> '쓸 에너지가 없어 일기 못 쓰는 사람'이 1탭으로 데이터 쌓고, AI가 알아서 분석해줍니다."

## 💬 이 문서 사용법

### 외부 공유 시
- 그대로 보내도 OK (5분이면 읽힘)
- 친구 / 인터뷰어 / 잠재 협력자 / 투자자 대상

### 내부 핑퐁 시
- 한 섹션 콕 집어서 "이 부분 어떻게 발전?" 질문
  - 예: "5️⃣ 핵심 기능 중 코칭 탭만 더 깊게 가고 싶어"
- 또는 "9️⃣ 안 할 것에 X도 추가해야 하지 않아?"
- 또는 "8️⃣ 로드맵 Phase E 어떻게 할까?"

### 업데이트 주기
- Phase 끝날 때마다 5️⃣ 기능 + 8️⃣ 로드맵 갱신
- 새 결정 났을 때 9️⃣ 안 할 것 추가
- 큰 변화 있을 때 1️⃣ 한 줄 소개 재검토 (원칙 1: 왜? 매주)
