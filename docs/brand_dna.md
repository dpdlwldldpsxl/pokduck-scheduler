# 브랜드 DNA

이 파일은 나의 정체성이야. 모든 콘텐츠, 상품, 전략이 여기서 출발해. 흔들릴 때 돌아오는 곳.

---

## 시작하는 법

아래 형식으로 기본 정보만 입력하면, AI 코치가 인터뷰를 통해 이 파일의 모든 항목을 완성해줘.

```
비전: "나는 ___다. ___에 대해 말한다. 대상은 ___. ___을 돕는다."
콘텐츠 주제: 권위: ___ / 성장: ___ / 진정성: ___
내 이야기: 과거: ___ / 전환점: ___ / 현재: ___
타겟의 고통: "___" / "___" / "___"
```

### 예시
```
비전: "나는 태오다. AI 기반 1인 비즈니스 시스템에 대해 말한다.
       대상은 퇴사하고 싶거나 1인 비즈니스를 시작하려는 직장인.
       하루 1~2시간으로 30일 안에 수익 시스템을 만들도록 돕는다."
콘텐츠 주제: 권위: AI 자동화, 클로드 코드 / 성장: 퍼스널 브랜드, 수익화 / 진정성: 퇴사 이야기, 번아웃
내 이야기: 과거: 삼성전자, 매일 출근이 두려웠다 / 전환점: 퇴사 후 유튜브로 연 1억, 근데 번아웃 / 현재: AI 자동화로 하루 1시간 운영
타겟의 고통: "퇴사하고 싶은데 뭘 해야 할지 모르겠어요" / "콘텐츠 뭘 올려야 할지 모르겠어요" / "시작했는데 반응이 없어서 지쳐요"
```

### 흐름
1. 위 형식으로 기본 정보 입력
2. AI 코치가 강점, 약점, 사명, 차별점을 인터뷰 (라운드 1)
3. AI 코치가 비전, 톤, 금기사항, 수익화를 인터뷰 (라운드 2)
4. 인터뷰 답변을 기반으로 아래 모든 항목이 자동 완성
